# Moode-Audio-Hub
Smart power management and audio control hub for Raspberry Pi 4 running Moode Audio, powered by ATtiny13.


# 🎵 Moode Audio Hub

**Moode Audio Hub** — це апаратно-програмне DIY-рішення для автоматизації, інтелектуального керування живленням та розширення функціоналу аудіоплеєра на базі **Raspberry Pi 4** під керуванням операційної системи **Moode Audio**.

Проєкт об'єднує три основні підсистеми:
1. **Контролер живлення на базі ATtiny13:** Регулює роботу реле живлення та забезпечує повний цикл безпечного вимкнення комп'ютера (Safe Shutdown). Стан системи відображається за допомогою двоколірного світлодіода.
2. **Аудіо-інтерфейс:** Звукова карта (ЦАП), підключена безпосередньо до GPIO (I2S/USB) для виведення Hi-Fi звуку.
3. **Органи керування:** Фізичний тумблер ON/OFF для керування живленням, а також USB-енкодер для апаратного регулювання рівня гучності та контролю відтворення (Start/Stop).

---

## 🟢 Режими індикації стану системи (Двоколірний LED, спільний катод)

* **🔴 Червоний (стабільно світиться):** Режим очікування (Standby). Живлення подано на пристрій, але Raspberry Pi вимкнена.
* **🟢 Зелений (повільно блимає):** Етап завантаження (Booting). Реле замкнулось, операційна система ініціалізується.
* **🟢 Зелений (стабільно світиться):** Робочий режим (Operational). Система повністю завантажена, веб-інтерфейс та сервіси плеєра готові до роботи.
* **🟢 Зелений (швидко блимає):** Процес вимкнення (Shutdown). Виконується безпечне завершення роботи ОС перед фізичним знеструмленням.

---

## ⚙️ Логіка взаємодії (ATtiny13 <-> Raspberry Pi 4)

Проєкт реалізує повністю автоматичне узгодження станів живлення:

1. **Ввімкнення:** Переведення тумблера в положення ON запускає контролер ATtiny13, замикається реле живлення, Raspberry Pi починає завантаження. Світлодіод повільно блимає зеленим.
2. **Контроль готовності:** Коли сервіси Moode Audio повністю активні, система подає логічну `1` на **GPIO 23** (підключений до PB1 `Download complete`). Світлодіод переходить у режим стабільного зеленого світіння.
3. **Ініціація вимкнення:** Переведення тумблера в положення OFF замикає лінію вимкнення. Скрипт на Raspberry Pi фіксує зміну рівня на **GPIO 6** і запускає команду `systemctl poweroff`. Світлодіод швидко блимає зеленим.
4. **Повне знеструмлення:** Після завершення процедури Shutdown, Raspberry Pi 4 вимикає внутрішню лінію **3.3V** (підключена до PB2 `Shutdown complete`). Зникнення напруги сигналізує ATtiny13, що ОС безпечно завершила роботу. Контролер розмикає реле та вмикає червоний світлодіод режиму очікування.

## 🔧 Налаштування служб автозапуску в Moode Audio

Для повноцінної інтеграції з ОС Linux у системі розгорнуто дві служби `systemd`.

### 1. Підсистема відстеження повної готовності (Signal Ready)

Служба очікує підняття веб-інтерфейсу та ключових аудіо-сервісів, після чого виставляє високий рівень на GPIO 23 за допомогою утиліти `gpioset`.

* **Скрипт `/usr/local/bin/moode-ready.sh`:**
```bash
#!/bin/bash

# Очікування відповіді від локального веб-сервера
while ! curl -fsS -o /dev/null http://localhost/; do
    sleep 1
done

# Встановлення логічної "1" на GPIO 23 утилітою gpioset
exec /usr/bin/gpioset --chip gpiochip0 23=1
```

* **Служба `/etc/systemd/system/moode-ready.service`:**
```ini
[Unit]
Description=moOde ready signal
After=nginx.service php8.4-fpm.service mpd.service
Requires=nginx.service php8.4-fpm.service mpd.service

[Service]
Type=simple
ExecStart=/usr/local/bin/moode-ready.sh
Restart=no

[Install]
WantedBy=multi-user.target
```

### 2. Підсистема безпечного вимкнення (Safe Shutdown)

Служба відстежує стан сигналу від тумблера за допомогою енергоефективного моніторингу подій фронту (`gpiomon`) без навантаження на процесор.

* **Скрипт `/usr/local/bin/gpio6-shutdown.sh`:**
```bash
#!/bin/bash
# Очікування події вимкнення на GPIO 6
/usr/bin/gpiomon --chip gpiochip0 --edges rising --num-events 1 GPIO6
# Ініціація коректного вимкнення системи
/usr/bin/systemctl poweroff
```

* **Служба `/etc/systemd/system/gpio6-shutdown.service`:**
```ini
[Unit]
Description=Shutdown on GPIO6 command
After=multi-user.target

[Service]
Type=simple
ExecStart=/usr/local/bin/gpio6-shutdown.sh
Restart=no

[Install]
WantedBy=multi-user.target
```

_Не забудьте зробити обидва скрипти виконуваними за допомогою команди `chmod +x` та активувати служби через `systemctl enable --now`._

## 🎛️ Апаратне керування звуком (USB-енкодер)

Для регулювання гучності та керування відтворенням використовується USB HID-енкодер, який розпізнається системою як мультимедійна клавіатура. Обробка натискань та прокручування реалізована через системний демон `triggerhappy`.

### Конфігурація гарячих клавіш `/etc/triggerhappy/triggers.d/moode.conf`:

```ini
# Збільшення гучності на 2% при прокручуванні праворуч
KEY_VOLUMEUP    1      /var/www/util/vol.sh --up 2

# Зменшення гучності на 2% при прокручуванні ліворуч
KEY_VOLUMEDOWN  1      /var/www/util/vol.sh --dn 2

# Перемикання Play/Pause при натисканні на кнопку енкодера
KEY_MUTE        1      /usr/bin/mpc toggle
```

*Після збереження файлу конфігурації необхідно перезапустити демон команди: `sudo systemctl restart triggerhappy`.*

## 🛠️ Особливості монтажу та конструкції

Оскільки звукова карта встановлюється на GPIO-роз'єм Raspberry Pi 4 і перекриває доступ до інших пінів, для підключення плати керування та організації живлення було використано **GPIO розширювач (Y-splitter)** з конфігурацією:
* **Вхід:** `40-pin Female` — підключається безпосередньо до GPIO Raspberry Pi.
* **Виходи:** Два паралельні роз'єми `40-pin Male`.

### Схема розміщення та комутації:
1. **Перший роз'єм 40-pin Male:** З'єднується зі звуковою картою (ЦАП) за допомогою гнучкого шлейфа довжиною **10 см**. Це дозволяє вільно розмістити звукову карту та зручно вивести аудіо-роз'єми на панель корпусу.
2. **Другий роз'єм 40-pin Male:** Використовується для комутації плати керування:
   * **Керуючі лінії:** Сигнали GPIO 6, GPIO 23, лінія контролю 3.3V та GND підпаюються до відповідних контактів роз'єму окремими тонкими провідниками.
   * **Магістраль живлення:** Через цей же роз'єм (піни +5V та GND) подається основне силове живлення **+5В** з плати керування (після реле) для живлення самої Raspberry Pi 4 та звукової карти.

⚠️ *Важливе зауваження: При такій схемі живлення подається в обхід штатного роз'єму USB-C Raspberry Pi. Категорично забороняється одночасно підключати зовнішній блок живлення в USB-C роз'єм малинки та подавати +5В з плати керування на GPIO!*
